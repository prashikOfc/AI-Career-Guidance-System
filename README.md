# 📖 Overview

The **AI-Based Career Guidance System** is an intelligent web application designed to help students and job seekers make informed career decisions. It combines Artificial Intelligence with resume analysis, personalized career recommendations, and an AI-powered chatbot to guide users based on their skills, interests, and qualifications.

This project was developed as a **collaborative team project** during a **30-Day Placement Training Program** to gain practical experience in full-stack web development and AI integration.

# 🚀 Installation

### Clone Repository

```bash
git clone https://github.com/prashikOfc/AI-Career-Guidance-System.git
```

### Navigate to Project

```bash
cd AI-Career-Guidance-System
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Run Application

```bash
python run.py
```
